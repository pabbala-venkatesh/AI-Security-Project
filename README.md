# AI Security Project

## Overview
A beginner-friendly cybersecurity project built with Python to explore security checks, risk detection, and safer AI-assisted workflows.

## Objectives
- Learn Python through practical security development.
- Identify potential security risks in test data.
- Explore phishing detection and suspicious message analysis.

- Test security controls in a safe local environment.
